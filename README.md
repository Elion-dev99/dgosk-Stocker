# StockPilot 静的Web版

## 起動方法
1. ZIPを展開します。
2. `index.html` をダブルクリックします。
3. ブラウザーでログインします。

## デモログイン
- メール: `admin@example.com`
- パスワード: `password123`

## 主な機能
- ログイン画面
- ダッシュボード
- 商品CRUD
- 月2回の在庫チェック
- 在庫・消費分析
- 在庫切れ予測
- 推奨発注量
- 発注済み記録
- 履歴削除
- CSV書き出し・読み込み
- 設定
- localStorage永続化
- レスポンシブ表示

## ファイル構成
- `index.html`
- `css/style.css`
- `js/app.js`

## 重要
これはブラウザーだけで動くプロトタイプです。データはブラウザーのlocalStorageに保存されます。実際のサービス公開では、パスワードをJavaScriptに保持せず、HTTPS、サーバー側認証、データベース、権限制御、監査ログ、バックアップ、CSRF対策、レート制限を実装してください。
